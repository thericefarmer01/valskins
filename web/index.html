Know their skins
before they mention them.

valskins shows every equipped weapon skin on your team the second a Valorant match starts. Vandal, knife, chroma variant, gun buddy — all of it, before anyone has fired a shot.

Download for Windows Source on GitHub

One .exe, about 20 MB. No installer, no admin, no account.

How to use it

  1. Download valskins.exe and put it anywhere you like.
  2. Windows will warn that the publisher is unknown — the build isn't code signed. More info → Run anyway.
  3. Start Valorant like normal, then open valskins. It says waiting for match once it's connected.
  4. Queue up. Agent select fills in the roster; the skins appear the instant round 1 begins.

Why there's no login

It already knows who you are

The Riot client running on your PC hands the app a session token. Typing your Riot password into third-party software is both unnecessary and the fastest way to lose your account.

Read-only

It calls the same endpoints the game client calls, plus a public asset CDN for skin names. No game memory, no injection, nothing written anywhere.

Not an overlay

It's an ordinary window you alt-tab to. Nothing is drawn on top of Valorant, which is the part that actually carries risk.

Also works on your other screen

Click watch on another device and valskins hands you a link for your Mac, phone, or second monitor — same live view, while the game stays fullscreen. The link is token-gated and dies when you close the app.

Unofficial and not endorsed by Riot Games. It uses undocumented client endpoints, so a patch can break it. Report an issue.
